# Antigravity Design Sandbox 🎨

Welcome to the UI Sandbox!

This directory is a safe space for Antigravity to prototype, design, and visually iterate on new UI components before integrating them into the main production codebase.

## How it works:
1. When you request a new component or design change, Antigravity will create temporary HTML/CSS/JS files here.
2. Antigravity will use its built-in browser to render these local files, visually inspect them, and auto-correct any design flaws.
3. Once the design is polished and you approve it, the code will be carefully merged into your main project.

*Note: Files in this folder are temporary and exploratory. Do not link to them from production code.*
